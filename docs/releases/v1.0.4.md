AVI files play properly: old video formats now go through FFmpeg.

## Install

Download `exo-player-v1.0.4.apk` below and open it on the Thor (or `adb install -r exo-player-v1.0.4.apk`). It installs over v1.0.1 and later and keeps your keys, library and progress.

## What's new

- **AVI (Xvid and DivX) no longer glitches.** The Thor has no hardware decoder for MPEG-4 Part 2, and Android's software one only handles its basic form, so B-frames, quarter-pixel and global motion came out blocky, smeared or jumping. These files now go to the app's own FFmpeg, which handles all of it, including DivX's "packed B-frames".
- **More old and unusual video plays:** DivX 3 (tagged MP43), MPEG-1/2, H.263, Motion JPEG, and 10-bit H.264 ("Hi10P", common in older anime releases), whenever the Thor has no decoder of its own for them.
- **Modern video is unchanged:** H.264, HEVC, VP9 and AV1 stay on the hardware.
- **Diagnostics** (Select + Start) lists the video formats FFmpeg plays.
- The APK is about 2 MB smaller: FFmpeg is now built for the Thor's chip only.

## Tested

102 tests on a PC. FFmpeg's decoding was checked on the PC with the same FFmpeg 6.0 and the same steps the app takes: Xvid and DivX AVI with B-frames (packed too), Xvid in MKV, DivX 3, Motion JPEG and 10-bit H.264 all decode every frame in order, with no errors.

## Known limits

- Not yet run on the Thor: please try an AVI that glitched before. If one still misbehaves, the diagnostics page and the file's name help.
- DivX 3 files tagged "DIV3" aren't recognised by the AVI reader yet (those tagged "MP43" are).
- The last few frames of a file handled by FFmpeg (about 0.2 s) aren't shown.
