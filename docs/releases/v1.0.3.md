Each season with its own description.

## Install

Download `exo-player-v1.0.3.apk` below and open it on the Thor (or `adb install -r exo-player-v1.0.3.apk`). It installs over v1.0.1 or v1.0.2 and keeps your keys, library and progress.

## What's new

- **Season descriptions are the season's own.** TMDB often has no English description for anime seasons, and the app used to show the whole show's description on every season instead.
- **AniList fills them in for anime.** On ⟳ Fetch info, seasons TMDB left empty get AniList's description, where each season is an entry of its own. An entry is used only when it started the same month (give or take one) as TMDB's season, so a season never shows another's text. Press ⟳ Fetch info once for anime you've already fetched.
- A season with no description anywhere shows its name, year and episodes only.

## Tested

96 tests on a PC. A live check against AniList finds Bungo Stray Dogs' five seasons, starting April 2016, October 2016, April 2019, January 2023 and July 2023, matching TMDB's.

## Known limits

- **AVI files (Xvid/DivX) can glitch:** the Thor decodes their video with Android's basic MPEG-4 decoder, which doesn't handle everything those files use. A fix (FFmpeg video decoding) is planned.
- The v1 gates (on-device test, battery against VLC) are still to run on the Thor.
