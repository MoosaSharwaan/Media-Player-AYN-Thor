Playback info, to find out why a file plays badly.

## Install

Download `exo-player-v1.0.5.apk` below and open it on the Thor. It installs over v1.0.1 and later and keeps everything.

## What's new

- **Playback info on the paused screen.** Pause a film and the bottom of the top screen shows what is decoding it and how it's going:
  `Video  FFmpeg mpeg4 · 720×400 · 23.98 fps · 3 dropped`
  `Audio  c2.android.mp3.decoder · EN · Stereo · MP3`
  plus "waited N×" when playback had to stop for the file. It tells a slow decoder (dropped frames) from a slow file (waits) or troublesome sound.
- **Diagnostics** (Select + Start) starts with the app's version, so a photo of it says which build is installed.

## If an AVI still lags

Play it for a minute where it lags, pause, and send a photo of the top screen. "FFmpeg" in the Video line means the new decoder is in use; a `c2.` name means it isn't.
